# 受控伪距—钟差可辨识性审计

运行日期：2026-09-07。

## 状态与范围

这是本项目第一个**已经运行的计算检查**，但不是定位实验，也不是论文结论。脚本只对受控的线性化伪距几何做矩阵秩检查，没有使用月球轨道、真实传感器数据、里程计因子、运动模型或有来源的误差参数。

可复现命令：

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python tools/observability_audit.py \
  --output docs/observability_audit_controlled.json \
  --scan-output docs/observability_parameter_scan.csv \
  --prior-scan-output docs/observability_prior_scan.csv \
  --geometry-scan-output docs/observability_geometry_scan.csv
```

机器可读结果保存在 [`observability_audit_controlled.json`](observability_audit_controlled.json)。

## 已完成的检查

脚本以米为钟差状态单位，将每条单位权重伪距写成位置 Jacobian `-u` 和钟差 Jacobian `1`，再通过 Schur complement 消去钟状态。当前回归测试检查：

- 单历元一至四颗卫星加未知共同钟差的有效位置秩；
- 三个历元、每历元一颗卫星、各历元钟差自由时的有效位置秩；
- 三个历元共享一个常值钟差时产生的跨历元耦合；
- 给单条伪距增加有限钟差先验后的方向信息；
- 零视线向量输入被拒绝。

## 当前结果

在本次受控输入下：

| 场景 | 消去钟差后的有效位置秩 |
| --- | ---: |
| 单历元，1 星，自由钟差 | 0 |
| 单历元，2 星，共同自由钟差 | 1 |
| 单历元，3 星，共同自由钟差 | 2 |
| 单历元，4 星，共同自由钟差，所用非退化几何 | 3 |
| 3 历元，每历元 1 星，每历元钟差独立 | 0 |
| 3 历元，每历元 1 星，三历元共享常值钟差 | 2 |

结果支持一个**模型实现层面的判断**：不能把“一颗卫星”直接等同于一个独立位置方向约束；结论会随钟模型改变。这只是预期线性代数性质的回归验证，不能据此声称发现了新的月球导航规律。

## 已加入的各向异性里程计单元试验

在五个三维位置历元之间加入了各向异性相对运动信息：受控弱方向为 x，弱方向增量信息为 1，正交强方向增量信息为 100；首历元以各向同性信息 100 固定规范自由度。加入伪距前，末历元的受控 x 方差为 4.01，y 方差为 0.05，符合“初始方差加四段增量方差”的解析结果。

随后使用两个纯受控的视线集合，二者每历元均有两条单位权重视线、共享一个常值钟差，而且视线都具有正 z 分量：

- 两条视线之差沿弱 x 方向时，末历元 x 方差由 4.01 降至 0.617655571635，相对下降 0.845971179143；
- 两条视线之差沿强 y 方向时，末历元 x 方差保持 4.01，相对下降为 0。

这已经验证了代码能够表达“相同观测数量、不同方向关系导致不同弱方向边际协方差收益”。它仍然只是构造性 sanity check：信息值、视线和常值钟差都是人为控制量，不能将 84.6% 写成现实月球系统的预期改善，也不能据此证明候选指标优于已有方法。

## 钟模型与参数扫描结果

当前已经加入三类跨历元钟模型：共享常值钟差、钟差随机游走、钟差—钟漂；各历元独立钟差继续作为无时间约束对照。钟差—钟漂状态转移使用 `b[k+1] - b[k] - d[k] * dt` 与 `d[k+1] - d[k]`，伪距只直接观测钟差，不直接观测钟漂。

对于每历元两条对称视线的方向扫描，两条视线作差可以在同历元消去共同钟差。因此，本次 189 个组合中，三种钟模型给出了相同的弱方向收益曲线。这不是“钟模型通常不重要”，而是该对称几何对钟差不敏感，说明它适合隔离方向效应，却不适合单独评价钟模型。

方向扫描覆盖视线差与弱方向夹角 0° 至 90°（每 15°）、强弱信息比 10/100/1000、测距信息权重 0.1/1/10，以及常值、随机游走和钟差—钟漂三种模型。在所有 27 组固定条件下，弱方向相对方差收益均随夹角单调不增，并在 90° 降至零。完整 189 行结果保存在 [`observability_parameter_scan.csv`](observability_parameter_scan.csv)。这里的“连续”仅指离散角度网格上没有反向跳变，尚不是解析单调性证明。

为真正检查钟模型，又增加了每历元只有一条固定视线的受控场景。此时相对弱方向方差下降依次为：常值钟差 0.541061224071、钟差随机游走 0.257010647582、钟差—钟漂 0.05917672611、逐历元独立钟差 0。该排序只针对当前人为信息参数；它说明实现能够表现钟动态假设的影响，不说明哪种模型或数值符合月球接收机振荡器。

## 量纲化与先验审计

代码新增了带单位的敏感性接口：位置和等效钟差使用米，钟漂使用米/秒，伪距权重由 `1 / sigma_rho^2` 生成。简单钟差随机游走的单步方差为 `q_b * dt`；钟差—钟漂模型采用状态转移 `F=[[1, dt], [0, 1]]`，并暂以相互独立的 `q_b * dt` 和 `q_d * dt` 作为两类过程残差方差。后者只是可审计的简化敏感性模型，并没有声称等价于某一真实振荡器的完整 power-law 噪声模型。

参数、单位、取值和证据状态单独保存在 [`observability_parameter_registry.csv`](observability_parameter_registry.csv)。其中伪距定义和 Allan 偏差分析方法分别链接 ESA Navipedia 和 NIST 手册；当前使用的所有数值仍明确标记为“敏感性值”，没有伪装成这些来源推荐的月球设备参数。

初始先验扫描使用 10 个一秒历元、每历元一条固定视线、10 m 伪距标准差；位置锚定标准差取 0.1/1/10 m，初始钟差标准差取 0.1/1/10/100/1,000,000 m。完整 30 行结果保存在 [`observability_prior_scan.csv`](observability_prior_scan.csv)。在每个固定钟模型和位置先验组内，放松初始钟差先验均未增加相对方差收益。例如位置先验为 10 m 时：

- 钟差随机游走模型的相对收益从钟先验 0.1 m 时的 0.438692 降至近似无先验时的 0.003286；
- 钟差—钟漂模型从 0.392019 降至 0.001893。

这表明先前受控排序确实可能强烈依赖初始钟先验；同时，位置锚定也改变基线绝对标准差和相对收益，二者必须随结果共同报告。这里的近似无先验以有限数值 `1,000,000 m` 实现，不等同于严格删除规范约束。

## 非对称几何验证

新增 28 个有量纲的几何检查：基准使用两条 45° 仰角、各 10 m 标准差的视线；然后每次只改变一项，分别将第二仰角改为 35°、第二测距标准差改为 20 m，或令方位角每历元变化 1°。完整结果保存在 [`observability_geometry_scan.csv`](observability_geometry_scan.csv)。

四类几何中，方向收益总体仍随初始夹角增大而减弱，但不再把“90° 必须为零”作为通过条件。在当前构造中，仅改变仰角或噪声而保持水平视线差严格沿 y 时，90° 对弱 x 的收益仍为零；加入随时间变化的方位角后，90° 初始条件下保留了 0.005607 的相对方差收益。这个小残余来自后续历元出现 x 分量，而不是数值异常。

## 仍未验证

- 已完成量纲一致的敏感性参数化，但数值仍无设备依据；尚未加入测距偏差或相关误差。
- 尚未用 LuPNT 或其他来源生成真实轨道视线。
- 尚未运行 S3LI、LuSNAR 或 LunaPolaris，也没有实际定位误差结果。
- 尚未比较候选指标与卫星数、GDOP 或里程计退化指标。

下一步不再增加更多任意参数扫描，而应为钟过程噪声和伪距误差找到适用系统、时间尺度明确的数值依据，并将当前简化随机游走与 Allan 偏差对应的噪声类型逐项核对；随后接入 LuPNT 视线或真实里程计输出。目前仍不进入完整紧耦合系统。
